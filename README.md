# 株式会社トシ・ランドスケープ 社内ポータル（モック）

社内ポータルサイトの見た目・画面遷移・使い勝手を確認するためのクリック可能なモックです。
バックエンド・DB・実認証・外部API連携は行わず、すべてフロントエンドのダミーデータで動作します。

## 起動方法

```bash
npm install
npm run dev
```

起動後、表示されるURL（例: http://localhost:5173 ）をブラウザで開いてください。
「管理者」または「現場社員」を選ぶ擬似ログイン画面が表示されます（パスワード不要）。

その他のコマンド:

```bash
npm run build    # 本番ビルド（型チェック含む）
npm run preview  # ビルド結果をローカルで確認
npm run lint      # oxlint によるコード検査
```

## フォルダ構成

```
src/
├── types/            # 型定義（取引先・売上・報告・カルテ等）
├── data/             # ダミーデータ（取引先・売上・完了報告・カルテサンプル・お知らせ・スケジュール）
├── context/           # 擬似ログイン状態（AuthContext）
├── components/
│   ├── layout/        # 共通レイアウト（サイドバー・ハンバーガーメニュー・ナビ構成）
│   ├── ui/             # 汎用UIパーツ（カード・指標カード・バッジ・ボタン等）
│   └── charts/         # recharts を使ったグラフコンポーネント
├── features/           # 画面ごとの実装（ログイン・ダッシュボード・取引先・データ取込・校正AP・カルテ作成AP等）
└── lib/                # 金額・日付フォーマット等の共通ユーティリティ
```

## ダミーデータの場所と差し替え方

すべて `src/data/` 配下の TypeScript ファイルにまとまっています。本番データに差し替える際は、
このディレクトリのファイルを実データ取得ロジック（API呼び出し等）に置き換えてください。

| ファイル | 内容 |
|---|---|
| `clients.ts` | 取引先マスタ（10件） |
| `sales.ts` | 売上データ（取引先×3部門×年月、2023〜2025年度分。デモ用に決定論的な疑似乱数で自動生成） |
| `reports.ts` | 完了報告（現場名・取引先・担当・人工・ごみ量・日付） |
| `karte.ts` | カルテサンプル（所見①〜⑥の正誤例）と文章校正APで使う簡易ルール |
| `news.ts` / `schedule.ts` | お知らせ・スケジュールのダミーデータ |

## 権限（擬似ログイン）について

- **管理者**：売上額を含む全ての実績情報を閲覧できます。
- **現場社員**：売上額など金額に関わる情報は「権限がないため非表示です」として制限表示されます（人工・ごみ量は表示されます）。データ取込メニューも非表示になります。

ログイン状態はブラウザのセッションストレージに保存されるため、リロードしてもログイン状態が保持されます。

## 作り込み済みの主要画面

- 擬似ログイン（`/login`）
- ポータルトップ（`/`）
- 実績ダッシュボード（`/dashboard`）：期間・年度・取引先・部門でのフィルタ、指標カード、月別売上推移／部門別構成比／取引先別ランキングのグラフ
- 取引先一覧・詳細（`/clients`, `/clients/:id`）：基本情報／ダッシュボード／作業履歴のタブ切替
- データ取込（`/data-import`）：ファイル選択→ダミーの取込結果・表記ゆれ検出結果を表示
- 文章校正AP（`/proofreading`）：カルテ本文の表記ゆれ・記入漏れをハイライト表示。「完全修正／指摘のみ」を切替可能
- カルテ作成AP（`/karte/new`）：入力フォーム→プレビュー表示
- お知らせ・スケジュール（`/company/news`, `/company/schedule`）

上記以外のメニュー項目（各部門の業務マニュアル・フォーマット等）は「準備中」のプレースホルダーページです。
